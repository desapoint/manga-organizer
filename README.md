# Manga Organizer

A documentation-first project for a unified, self-hosted manga library, acquisition manager and reader for Windows and Unraid/Docker.

**Status:** discovery and feature selection; no runnable app yet.

- [Roadmap and acceptance gates](docs/ROADMAP.md)
- [Contributing and audit protocol](CONTRIBUTING.md)

The goal is to combine the best workflows from five upstream projects without requiring five separate applications. The feature inventory is a candidate backlog, not a commitment to implement everything. No upstream code has been imported; license and dependency choices require review before implementation.
